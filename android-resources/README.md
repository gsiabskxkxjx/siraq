# صوت الأذان (مضمَّن في التطبيق)

الملف `adhan.mp3` في هذا المجلد هو صوت الأذان الرسمي للتطبيق. يُنسخ وقت البناء إلى `res/raw/adhan` داخل الـAPK، ويشغّله منبّه الأذان الأصلي (قناة صوت المنبّه) فيُسمع حتى والهاتف صامت.

لتغيير الأذان: استبدل `adhan.mp3` بملف آخر (الاسم نفسه، حروف صغيرة)، ثم ارفعه إلى GitHub وابنِ الـAPK وثبّته. على أندرويد 8+ قد يلزم حذف قناة «الأذان» من إعدادات إشعارات التطبيق ليتحدّث صوت القناة.

لا يُرفع الأذان من تطبيق المتحكم ولا يصل عبر الحزم.
