# مفتاح التوقيع الشخصي للاختبار

هذا المفتاح **للتجربة الشخصية فقط**. كلمة سره موجودة في المستودع عمداً (`siraj-personal-test`، الاسم المستعار `siraj`) ليُوقَّع كل بناء بالمفتاح نفسه، فيُثبَّت كل إصدار جديد **فوق** القديم دون حذف التطبيق وفقدان بياناتك.

- لا تنشر هذا المستودع علناً ما دام فيه المفتاح.
- لا ترفع هذا الـAPK إلى متجر Google Play. للنشر في المتجر أنشئ مفتاحاً جديداً سرّياً وخزّنه في GitHub Secrets.
- إن حذفت المفتاح أو غيّرته فسيرفض أندرويد تثبيت الإصدار الجديد فوق القديم (احذف التطبيق القديم أولاً).
