# قوالب الاستيراد

كل ملف هنا مصفوفة JSON تطابق ما تقبله شاشات الاستيراد في التطبيق فعلاً.

| الملف | أين يُستورد | ماذا يحدث |
|---|---|---|
| `books-import.template.json` | إدارة سِراج ← استيراد | تُضاف الكتب **مقترحاتٍ بحالة «بانتظار الموافقة»**، ولا تُنشر تلقائياً. العنوان والمؤلف والقسم إلزامية، والمكرَّر يُتخطى. |
| `duas-import.template.json` | إدارة سِراج ← الأدعية ← استيراد | يُرفض أي عنصر بلا مصدر (الكتاب + الصفحة/الجزء أو رابط). |
| `narrations-import.template.json` | الموسوعات ← وثائق واستيراد (المجموعة: روايات) | يلزم مصدر واحد على الأقل فيه الكتاب مع الصفحة أو رقم الحديث؛ يُتحقق من الآيات؛ وأحكام العلماء تُنسب لقائلها ومصدرها. |
| `tafsir-import.template.json` | الموسوعات ← وثائق واستيراد (المجموعة: تفسير) | `verse` بصيغة `2:255` أو `2:255-257`، ومصدر بصفحة. |

تنبيهات:
- لا تُدرَج نصوص دينية دون مصدر. القيم بين `< >` أمثلة يجب استبدالها.
- لا تحتوي القوالب نصوصاً دينية حقيقية.
- الاستيراد لا يرفع ملفات PDF؛ تُرفق الملفات يدوياً من شاشة الكتاب بعد توثيق حالة الحقوق.
