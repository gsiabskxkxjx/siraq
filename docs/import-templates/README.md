# قوالب الاستيراد

كل ملف هنا مصفوفة JSON تطابق ما تقبله شاشة **استيراد من ملف** في تطبيق **سِراج — التحكم** (المحتوى ← استيراد من ملف). سِراج نفسه لا يستورد شيئاً من المستخدم؛ المستورد يدخل تطبيق التحكم **مسودات** ثم يعلّمها الناشر «جاهز» ويصدرها في حزمة موقّعة.

| الملف | نوع الاستيراد | ماذا يحدث |
|---|---|---|
| `books-import.template.json` | كتب | تُضاف **مسودات**. العنوان والمؤلف والقسم والمصدر إلزامية؛ المكرَّر (عنوان+مؤلف، في سِراج أو في مسوداتك) يُرفض. |
| `duas-import.template.json` | أدعية وزيارات | يُرفض أي عنصر بلا مصدر (الكتاب + الصفحة/الجزء أو رابط). |
| `narrations-import.template.json` | مداخل موسوعة (اختر المجموعة: روايات) | يلزم مصدر واحد على الأقل فيه الكتاب مع الصفحة أو رقم الحديث؛ يُتحقق من الآيات؛ وأحكام العلماء تُنسب لقائلها ومصدرها. |
| `tafsir-import.template.json` | مداخل موسوعة (اختر المجموعة: تفسير) | `verse` بصيغة `2:255` أو `2:255-257`، ومصدر بصفحة؛ العنوان والمفسّر يُشتقان من `book` إن غابا. |

تنبيهات:
- لا تُدرَج نصوص دينية دون مصدر. القيم بين `< >` أمثلة يجب استبدالها.
- لا تحتوي القوالب نصوصاً دينية حقيقية.
- لا ملفات PDF ولا أغلفة في أي حزمة: بيانات ببليوغرافية ورابط خارجي فقط.
- لعنصر مداخل يمكن وضع الحقل `collection` داخل كل عنصر بدل اختيار المجموعة من القائمة.
