# سِراج — التحكم: دليل الناشر

تطبيق **«سِراج — التحكم»** هو الأداة الوحيدة التي يصدر منها المحتوى الجديد لتطبيق **سِراج**. تطبيق سِراج نفسه للمستخدم فقط: لا حسابات، لا تسجيل أدمن، لا رفع ملفات ولا إضافة كتب أو أدعية من داخله.

```
┌──────────────────────────┐   ملف  .sirajpack   ┌──────────────────────┐
│  سِراج — التحكم (هاتفك)  │ ───────────────────▶ │  سِراج (للمستخدمين)  │
│  مفتاح سري مشفّر + محتوى │  موقّع ECDSA P-256   │  مفتاح عام فقط        │
└──────────────────────────┘                      └──────────────────────┘
        لا خادم • لا حسابات • لا إنترنت مطلوب
```

## الفكرة بإيجاز
1. تُنشئ في تطبيق التحكم **مفتاح نشر** (زوج مفاتيح). السري يبقى مشفّراً بعبارة مرور على هاتفك ولا يغادره إلا في نسخة احتياطية مشفّرة تحفظها أنت.
2. تضيف كتباً وأدعية ومداخل موسوعة **بمصادرها**، وتعلّم ما صحّ منها «جاهز للنشر».
3. تُصدر **حزمة** (`.sirajpack`): لقطة كاملة بكل الجاهز، موقّعة بمفتاحك.
4. المستخدم يفتح في سِراج: **المزيد ← تحديثات المحتوى** ← يختار الملف ← يرى المعاينة والتوقيع ← يثبّت.
5. سِراج **لا يقبل** إلا ما وقّعه مفتاح مضمَّن فيه، وأي تعديل بايت واحد على الملف يُبطل التوقيع.

## الإعداد لأول مرة (مرة واحدة)
1. **ثبّت تطبيق التحكم**: من GitHub ← Releases ← أحدث إصدار باسم `control-N` ← `SIRAJ-Control.apk`. يُثبَّت بجانب سِراج (معرّف مختلف `com.siraj.control`).
2. افتحه ← تبويب **المفتاح** ← اختر عبارة مرور (8 أحرف فأكثر) ← **إنشاء المفتاح**.
3. اضغط **نسخة احتياطية** واحفظ ملف `.sirajkey` خارج الهاتف (درايف، رسالة لنفسك…). **بدونه لو ضاع الهاتف ضاعت القدرة على النشر بهذا المفتاح.** الملف مشفّر؛ لا يفيد أحداً بلا عبارة المرور.
4. في الشاشة نفسها اضغط **نسخ المفتاح العام** (أو فتح ملف المفاتيح في GitHub). هذا الجزء علني وآمن.
5. الصقه في `assets/data/publisher-keys.js` داخل مستودع سِراج بين القوسين المربعين (المفتاح المضمَّن حالياً: `9df05ff68810d3a2`، ويُستبدل أو يُضاف إليه عند تغيير الناشر):

```js
window.SIRAJ_PUBLISHER_KEYS = [
  { "name": "الناشر", "id": "0123456789abcdef", "jwk": { "kty": "EC", "crv": "P-256", "x": "…", "y": "…" } }
];
```
   (من الهاتف: افتح الملف في GitHub ← أيقونة القلم ← الصق ← Commit.) أو أرسل لي المقطع وأضعه أنا.
6. انتظر بناء `SIRAJ.apk` الجديد (Actions) وثبّته. افتح **المزيد ← تحديثات المحتوى**: ستظهر **بصمة** مفتاحك (16 خانة)؛ **طابقها** مع بصمة تطبيق التحكم.

> الحزم لا تُقبل في سِراج إلا بتوقيع مفتاح مضمَّن في `publisher-keys.js`؛ أي مفتاح غيره (أو قائمة فارغة) تُرفض معه كل الحزم بوضوح. المفتاح المضمَّن في هذا الإصدار بصمته `9df05ff68810d3a2`: إن أنشأتَ مفتاحاً جديداً في التحكم فستختلف بصمته ويلزم إضافته.

## الاستعمال اليومي
| الشاشة | ماذا تفعل |
|---|---|
| **المحتوى ← كتبك** | عنوان، مؤلف (من الكتالوج أو جديد)، قسم، **مصدر البيانات (اسم أو رابط) إلزامي**، حالة الحقوق. لا ملفات كتب: بيانات ببليوغرافية ورابط خارجي فقط. |
| **المحتوى ← أدعيتك** | نص الدعاء/الزيارة **يلزمه كتاب + صفحة/جزء/رابط**. بلا نص يُنشر العنوان فقط بحالة «العنوان فقط». |
| **المحتوى ← مداخل الموسوعة** | 13 مجموعة (روايات، رواة، تفسير، أسباب نزول…). مصدر واحد على الأقل بموضع؛ حكم العالم ينسب لقائله ومصدره؛ الآيات بصيغة `سورة:آية`. |
| **استيراد من ملف** | قوالب JSON (انظر `docs/import-templates/`). المستورد يدخل **مسودة** بعد الفحص؛ المرفوض يُعرض سببه ولا يُحفظ. |
| **سحب من المضمّن** | يُخفي كتاباً/دعاءً موجوداً في سِراج (مثلاً وجدتَ فيه خطأً) عند تثبيت حزمتك التالية. |
| **إعلانات** | رسائل تظهر في إشعارات سِراج مرة واحدة عند التثبيت. |
| **الإصدار** | عنوان وملاحظات ← **توقيع الحزمة وإصدارها** ← يُحفظ/يُشارك الملف. «فحص ملف حزمة» يتحقق من أي ملف بمفتاحك. |

**لا نشر تلقائي:** كل عنصر يبدأ «مسودة». لا يدخل الحزمة إلا إذا علّمتَه «جاهز للنشر» **واجتاز الفحص**؛ وإن لم يجتز يُحفظ مسودة مع سبب الرفض. الإصدار نفسه يفحص كل الجاهز مرة أخرى ويمتنع عند أي خطأ، فلا تُصدر حزمة سيرفض سِراج جزءاً منها.

## الحزمة لقطة كاملة
ما في الحزمة هو **كل** ما تنشره الآن. تثبيتها في سِراج:
- يضيف/يحدّث عناصرها (بالمعرّف).
- **يحذف** ما كان من حزمك السابقة وغاب عن هذه (مثلاً أعدتَ كتاباً إلى مسودة).
- يخفي ما سحبتَه من المضمّن، ويرجعه إن رفعتَ السحب في حزمة لاحقة.
- لا يمسّ بيانات المستخدم (مفضلة، ملاحظات، تقدّم القراءة…).
- لا يستبدل عنصراً مضمّناً بنفس المعرّف (يُرفض ذلك العنصر وحده).

## حدود الأمان (بصراحة)
- **منع الرجوع:** لكل حزمة رقم يتصاعد دائماً؛ يرفض سِراج رقماً أقدم من المثبَّت من المفتاح نفسه، ويرفض رقماً مطابقاً بمعرّف مختلف. الرقم = `max(آخر رقم+1، الدقائق منذ 1970)` فلا يضيع التسلسل لو فُقدت بيانات التطبيق.
- **من يسرق ملف المفتاح وعبارة المرور** ينشر باسمك. اختر عبارة قوية ولا تخزنها بجانب الملف. التشفير: PBKDF2-SHA256 بـ600 ألف دورة + AES-GCM. يُقفل المفتاح تلقائياً بعد 10 دقائق، وعند إخفاء التطبيق أكثر من دقيقتين.
- **إن ضاع المفتاح أو سُرق:** أنشئ مفتاحاً جديداً، واستبدل المفتاح العام القديم في `publisher-keys.js` (أو أضف الجديد واحذف القديم) وابنِ سِراج. المستخدمون يحدّثون التطبيق فتُرفض حزم المفتاح القديم.
- **حدّ ما نضمنه:** التوقيع يثبت أن الحزمة منك ولم تُعدَّل؛ **لا يثبت صحة محتواها**. التدقيق في المصادر مسؤوليتك؛ والتطبيق يفرض فقط وجود مصدر وموضعه، لا صدقه.
- **لم يُجرَّب على هاتف حقيقي** من بيئة التطوير؛ اختُبر بمحاكاة Capacitor في Chromium (انظر `tests/control_native_flow.py`) وبتحقق مستقل من التوقيع بمكتبة Python `cryptography`.

## صيغة الملف (للمطوّرين)
```json
{ "format": "siraj-pack/1", "keyId": "<16 hex>", "alg": "ES256", "payload": "<نص JSON>", "sig": "<base64url r||s>" }
```
- التوقيع على بايتات UTF-8 لنص `payload` كما هو (بلا تطبيع)، ECDSA P-256 + SHA-256 عبر WebCrypto (اختير على Ed25519 لدعم WebView القديم).
- `keyId` = أول 16 خانة سداسية من SHA-256 للنص `x.y` (إحداثيا المفتاح العام).
- الحمولة: `{v:1, app:'SIRAJ', id, seq, created, title, notes, authors[], books[], duas[], entries[], withdraw:{books,duas,entries}, notices[]}`.
- القواعد المشتركة في `assets/js/schema.js` (نسخة واحدة يستعملها التطبيقان).

## بناء تطبيق التحكم
- يُبنى تلقائياً بـ `.github/workflows/android-control.yml` عند كل دفع (وسم الإصدار `control-<رقم>`، لا يُعلَّم «latest» ليبقى سِراج هو الأحدث).
- محلياً: `cd control && npm install && node ../scripts/prepare-control.mjs` ثم `npx cap add android` و`SIRAJ_ANDROID_DIR=control/android SIRAJ_IMAGES_DIR=control/assets/images SIRAJ_PERMS= python3 ../scripts/patch-android.py` ثم `npx cap sync android` وبناء Gradle كما في `docs/ANDROID.md`.
- يُوقَّع بالمفتاح الشخصي نفسه المستعمل لسِراج (للتجربة الشخصية فقط).
