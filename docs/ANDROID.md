# تحويل سِراج إلى تطبيق أندرويد (APK) عبر GitHub

التطبيق نفسه ويب (HTML/JS). نغلّفه بـ **Capacitor 8** داخل غلاف أندرويد، ويبني GitHub Actions ملف `SIRAJ.apk` تلقائياً عند كل دفع إلى الفرع `main`، دون الحاجة إلى حاسوب.

## كيف تحمّل الـAPK من الهاتف
1. افتح المستودع على GitHub من المتصفح (أو تطبيق GitHub).
2. تبويب **Actions** ← آخر تشغيل باسم «Build Android APK»: انتظر العلامة الخضراء (حوالي 6–12 دقيقة).
3. حمّل الملف من أحد مكانين:
   - تبويب **Releases** (أو «Releases» في يمين الصفحة الرئيسية) ← آخر إصدار ← **Assets** ← `SIRAJ.apk`. هذا هو الأسهل من الهاتف.
   - أو أسفل صفحة التشغيل في قسم **Artifacts** ← `SIRAJ-apk` (ملف مضغوط ZIP يحوي الـAPK).
4. افتح الملف من «التنزيلات». إن طلب أندرويد: **السماح بالتثبيت من هذا المصدر** (للمتصفح الذي نزّلت منه) ثم ثبّت.
5. إن كان المستودع خاصاً فتحتاج تسجيل الدخول في المتصفح نفسه بحساب GitHub.

## إن فشل البناء (علامة حمراء)
افتح التشغيل الفاشل ← الخطوة ذات X الحمراء ← انسخ آخر 30–40 سطراً من الخطأ وأرسلها لي لأصلحها. عند الفشل يُرفع أيضاً Artifact باسم `build-reports` فيه تقارير Gradle.

## ما الذي يحدث في البناء
| الخطوة | الملف |
|---|---|
| نسخ التطبيق إلى `www/` | `scripts/prepare-www.mjs` |
| جلب نص المصحف (Tanzil عبر AlQuran.cloud) والتحقق منه (114 سورة، 6236 آية) وتضمينه | `scripts/fetch-quran.mjs` (فشله غير قاتل) |
| جلب أحاديث عربية من Thaqalayn API وتضمينها (عيّنة ≤ 1500) | `scripts/fetch-thaqalayn.mjs` (فشله غير قاتل؛ يطبع العدد في سجل البناء) |
| إنشاء مشروع أندرويد | `npx cap add android` |
| الصلاحيات والأيقونة وشاشة البداية | `scripts/patch-android.py` |
| بناء APK | `./gradlew assembleDebug` |
| التوقيع بمفتاح ثابت | `scripts/sign-apk.sh` + `android-signing/` |
| النشر | Artifact + Release |

مشروع أندرويد نفسه **لا يُحفظ** في المستودع؛ يُولَّد في كل بناء (`android/` في `.gitignore`).

## التوقيع والتحديث
كل البناءات توقَّع بالمفتاح نفسه (`android-signing/siraj-personal.keystore`) فيُثبَّت الإصدار الجديد فوق القديم دون حذف بياناتك. المفتاح **للتجربة الشخصية فقط** وكلمة سره في المستودع؛ لا تنشر المستودع علناً، ولا ترفع هذا الـAPK إلى Google Play.

## ما يختلف في نسخة أندرويد
- لا حاجة إلى Service Worker: الملفات داخل التطبيق (تظهر في الإعدادات «غير مطلوب»).
- نص المصحف يُستورد من الملف المضمَّن أول تشغيل، وإن لم يُضمَّن وقت البناء فيُنزَّل من الإعدادات ← المصحف كما في المتصفح.
- تنزيل الملفات (نسخ احتياطية، تصدير) يمر عبر Filesystem + نافذة المشاركة لأن WebView لا يدعم تنزيل الروابط المحلية.
- الإشعارات المحلية (تنبيه الصلاة) **غير مفعّلة** في هذه النسخة؛ تحتاج إضافة `LocalNotifications` وإذن الإشعارات، وهي خطوة لاحقة.
- الموقع (القبلة/أوقات الصلاة) يطلب إذن الموقع من أندرويد.

## ما لم يُختبر
اختُبر منطق التطبيق في متصفح كروم (محاكاة الشاشات 360/390/430 والوضع الليلي) وبمحاكاة جسور Capacitor، **لكن لم يُشغَّل على هاتف حقيقي**، ولم تُشاهَد نتيجة بناء GitHub Actions من بيئة التطوير. أول بناء قد يحتاج إصلاحاً صغيراً.

## الأمر المحلي (اختياري، للمطوّرين)
```bash
npm install
node scripts/prepare-www.mjs
node scripts/fetch-quran.mjs        # اختياري
node scripts/fetch-thaqalayn.mjs    # اختياري (أحاديث)
npx cap add android
python3 scripts/patch-android.py
npx cap sync android
cd android && ./gradlew assembleDebug
```
يتطلب Node 22+ وJDK 21 وAndroid SDK 36.
