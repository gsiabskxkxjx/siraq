# تحويل سِراج إلى تطبيق أندرويد (APK) عبر GitHub

التطبيقات الثلاثة (سِراج و«سِراج — التحكم» و«سِراج — الأغلفة») ويب (HTML/JS). نغلّفها بـ **Capacitor 8** داخل غلاف أندرويد، ويبني GitHub Actions ملفين تلقائياً عند كل دفع إلى الفرع `main`، دون الحاجة إلى حاسوب:

| التطبيق | Workflow | الملف | وسم الإصدار | معرّف الحزمة |
|---|---|---|---|---|
| سِراج (للمستخدم) | `android.yml` «Build Android APK» | `SIRAJ.apk` | `apk-N` | `com.siraj.app` |
| سِراج — التحكم (للناشر) | `android-control.yml` «Build Control APK» | `SIRAJ-Control.apk` | `control-N` | `com.siraj.control` |
| سِراج — الأغلفة | `android-covers.yml` «Build Covers APK» | `SIRAJ-Covers.apk` | `covers-N` | `com.siraj.covers` |

تُثبَّت الثلاثة معاً على الهاتف. شرح الأغلفة في [`COVERS.md`](COVERS.md). شرح التحكم والمفتاح والحزم في [`CONTROL.md`](CONTROL.md).

## كيف تحمّل الـAPK من الهاتف
1. افتح المستودع على GitHub من المتصفح (أو تطبيق GitHub).
2. تبويب **Actions** ← آخر تشغيل باسم «Build Android APK»: انتظر العلامة الخضراء (حوالي 6–12 دقيقة).
3. حمّل الملف من أحد مكانين:
   - تبويب **Releases** (أو «Releases» في يمين الصفحة الرئيسية) ← آخر إصدار ← **Assets** ← `SIRAJ.apk`. هذا هو الأسهل من الهاتف.
   - أو أسفل صفحة التشغيل في قسم **Artifacts** ← `SIRAJ-apk` (ملف مضغوط ZIP يحوي الـAPK).
4. افتح الملف من «التنزيلات». إن طلب أندرويد: **السماح بالتثبيت من هذا المصدر** (للمتصفح الذي نزّلت منه) ثم ثبّت.
5. إن كان المستودع خاصاً فتحتاج تسجيل الدخول في المتصفح نفسه بحساب GitHub.

## إن فشل البناء (علامة حمراء)
افتح التشغيل الفاشل ← الخطوة ذات X الحمراء ← انسخ آخر 30–40 سطراً من الخطأ وأرسلها لي لأصلحها. عند الفشل يُرفع أيضاً Artifact باسم `build-reports` (أو `control-build-reports` لتطبيق التحكم) فيه تقارير Gradle.

## ما الذي يحدث في البناء
| الخطوة | الملف |
|---|---|
| نسخ التطبيق إلى `www/` | `scripts/prepare-www.mjs` |
| جلب نص المصحف (Tanzil عبر AlQuran.cloud) والتحقق منه (114 سورة، 6236 آية) وتضمينه | `scripts/fetch-quran.mjs` (فشله غير قاتل) |
| جلب أحاديث عربية من Thaqalayn API وتضمينها (عيّنة ≤ 1500) | `scripts/fetch-thaqalayn.mjs` (فشله غير قاتل؛ يطبع العدد في سجل البناء) |
| إنشاء مشروع أندرويد | `npx cap add android` |
| الصلاحيات (موقع، إشعارات، منبّهات) والأيقونة وأيقونة الإشعارات وصوت الأذان الاختياري وشاشة البداية | `scripts/patch-android.py` |
| بناء APK | `./gradlew assembleDebug` |
| التوقيع بمفتاح ثابت | `scripts/sign-apk.sh` + `android-signing/` |
| النشر | Artifact + Release |

مشروع أندرويد نفسه **لا يُحفظ** في المستودع؛ يُولَّد في كل بناء (`android/` في `.gitignore`).

## التوقيع والتحديث
كل البناءات (للتطبيقين) توقَّع بالمفتاح نفسه (`android-signing/siraj-personal.keystore`) فيُثبَّت الإصدار الجديد فوق القديم دون حذف بياناتك. (هذا مفتاح توقيع **APK** وهو غير مفتاح **نشر المحتوى** الذي يُنشئه الناشر في تطبيق التحكم.) المفتاح **للتجربة الشخصية فقط** وكلمة سره في المستودع؛ لا تنشر المستودع علناً، ولا ترفع هذا الـAPK إلى Google Play.

## ما يختلف في نسخة أندرويد
- لا حاجة إلى Service Worker: الملفات داخل التطبيق (تظهر في الإعدادات «غير مطلوب»).
- نص المصحف يُستورد من الملف المضمَّن أول تشغيل، وإن لم يُضمَّن وقت البناء فيُنزَّل من الإعدادات ← المصحف كما في المتصفح.
- تنزيل الملفات (نسخ احتياطية، تصدير) يمر عبر Filesystem + نافذة المشاركة لأن WebView لا يدعم تنزيل الروابط المحلية.
- **الإشعارات الحقيقية** (الأذان، التنبيه المسبق، تذكيرات الأدعية، المناسبات) عبر `@capacitor/local-notifications` (`assets/js/native-notify.js`): تُجدول على الهاتف بمنبّه النظام فتصل والتطبيق مغلق. بعد التثبيت: **المزيد ← مواقيت الصلاة** ← «تفعيل الآن» (أو إعدادات الصلاة) ← اسمح بالإشعارات، ثم اسمح بـ«المنبّهات والتذكيرات» ليصل الإشعار بالدقيقة (أندرويد 12+). زر «جرّب الإشعار (10 ث)» في إعدادات الصلاة يتأكد لك أنه يصل والتطبيق في الخلفية.
  - تُجدول 10 أيام قادمة وتُعاد الجدولة عند كل فتح أو تغيير موقع/إعداد؛ فافتح التطبيق مرة كل بضعة أيام. بعد إعادة تشغيل الهاتف تستعيد الإضافة المجدولة (صلاحية `RECEIVE_BOOT_COMPLETED`).
  - صوت الأذان داخل الإشعار: صوت إشعارات الهاتف افتراضياً. لإضافة أذان فعلي ضع ملفاً **مرخّصاً** `adhan.mp3` في `android-resources/` قبل البناء (التفاصيل هناك).
  - لا خادم دفع: لا شيء يصل من الناشر خارج الحزم. وبعض الهواتف تقيّد الخلفية (استثنِ سِراج من توفير البطارية).
  - الصلاحيات المضافة في `patch-android.py`: `POST_NOTIFICATIONS`، `SCHEDULE_EXACT_ALARM`، `USE_EXACT_ALARM`، `RECEIVE_BOOT_COMPLETED`، `WAKE_LOCK`، وأيقونة شريط الإشعارات `ic_stat_siraj` تُولَّد من الشعار.
- الموقع (القبلة/أوقات الصلاة) يطلب إذن الموقع من أندرويد.

## ما لم يُختبر
اختُبر منطق التطبيق في متصفح كروم (محاكاة الشاشات 360/390/430 والوضع الليلي) وبمحاكاة جسور Capacitor، **لكن لم يُشغَّل على هاتف حقيقي**، ولم تُشاهَد نتيجة بناء GitHub Actions من بيئة التطوير. أول بناء قد يحتاج إصلاحاً صغيراً. وبالنسبة للإشعارات: اختُبر منطق الجدولة وما يُرسَل إلى `LocalNotifications` بمحاكاة (`tests/notify_flow.py`)، أما **وصول الإشعار والصوت على هاتفك** فلم يُجرَّب؛ استعمل زر «جرّب الإشعار (10 ث)» وأبلغ بالنتيجة.

## تطبيق التحكم: ما يختلف
- مجلده `control/` له `package.json` و`capacitor.config.json` خاصان (`com.siraj.control`)، وبناؤه بـ `scripts/prepare-control.mjs` الذي ينسخ واجهة التحكم وملفات النواة المشتركة (`ui/storage/schema/packcrypto/navigation` + الأنماط) ويولّد `data/refs.js` (مراجع مصغّرة من بيانات سِراج) و`data/build-info.js`.
- `scripts/patch-android.py` يخدم التطبيقين بمتغيرات بيئة (`SIRAJ_ANDROID_DIR`, `SIRAJ_IMAGES_DIR`, `SIRAJ_ICON_BG`, `SIRAJ_SPLASH_BG`, `SIRAJ_PERMS`)؛ للتحكم: بلا صلاحيات (لا موقع ولا اهتزاز).
- حفظ الحزم والنسخ الاحتياطية يمر عبر Filesystem + نافذة المشاركة (`S.nativeSave`)، وزر الرجوع عبر إضافة `App`.
- قاعدة بياناته منفصلة (`siraj-control-db`) فلا تتداخل مع سِراج حتى لو شاركا الحزمة.

## الأمر المحلي (اختياري، للمطوّرين)
```bash
npm install
node scripts/prepare-www.mjs
node scripts/fetch-quran.mjs        # اختياري
node scripts/fetch-thaqalayn.mjs    # اختياري (أحاديث)
npx cap add android
python3 scripts/patch-android.py
npx cap sync android
cd android && ./gradlew assembleDebug
```
يتطلب Node 22+ وJDK 21 وAndroid SDK 36.

## القراءة الآلية (تحويل النص إلى كلام)
WebView أندرويد لا يوفّر غالباً `speechSynthesis`، لذلك يستعمل سِراج إضافة `@capacitor-community/text-to-speech` (محرك الهاتف نفسه) عبر `assets/js/tts.js`، ويعود إلى `speechSynthesis` في المتصفح. يضيف `scripts/patch-android.py` (مع `SIRAJ_TTS=1` في `android.yml`) عنصر `<queries>` لخدمة `TTS_SERVICE` احتياطاً لأندرويد 11+. القراءة بصوت **محرك هاتفك** وليست تلاوة بشرية؛ يلزم صوت عربي مثبّت (إعدادات الهاتف ← تحويل النص إلى كلام؛ مثلاً «خدمات الكلام من Google»). النص الطويل يُقسَّم إلى مقاطع ≤ 1500 حرف. **لم تُجرَّب على جهاز حقيقي** — اختبارها الآلي بمحاكاة الإضافة فقط.

## المظهر
واجهة سِراج بنمط «مخطوطة» (رقّ نهاري/ليلي، لازورد وذهب، خط Amiri) في `assets/css/makhtuta.css` فوق `style.css`. خط Cairo يبقى لتطبيق التحكم فقط (لا يُضمَّن في APK سِراج).
